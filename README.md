## 📖 Acerca del Proyecto

**Ahorrando Ando** nace con la finalidad de brindar a los usuarios una herramienta simple pero potente para tomar el control de sus finanzas personales. Permite registrar ingresos, gastos y establecer metas de ahorro a corto y largo plazo de forma clara y visual.

---

## ✨ Características Principales

* 💵 **Registro de Ingresos y Gastos:** Añade transacciones rápidamente clasificándolas por categoría.
* 🎯 **Metas de Ahorro:** Define objetivos monetarios y monitorea tu progreso en tiempo real.
* 📊 **Reportes Visuales:** Visualiza el flujo de tu dinero a través de gráficos y resúmenes mensuales.
* 🔒 **Privacidad y Seguridad:** Almacenamiento seguro de tus datos financieros.
* 📱 **Diseño Responsive:** Adaptado para ser utilizado desde cualquier dispositivo (Móvil, Tablet o Desktop).
